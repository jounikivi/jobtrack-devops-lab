# JobTrack Lite

JobTrack Lite on työnhaun seurantasovellus, johon käyttäjä voi kirjata työpaikkahakemuksia ja seurata niiden etenemistä.

## Projektin tavoite

Projektin tavoitteena on kerrata Reactin ja TypeScriptin käyttöä sekä harjoitella Git-pohjaista työskentelyä, automaattista testausta ja CI/CD-putken rakentamista. Valmis sovellus julkaistaan GitHub Pagesissa, ja repositorio toimii rehellisenä portfolionäyttönä projektin toteutuksesta ja oppimisprosessista.
